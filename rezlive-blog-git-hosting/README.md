# RezLive Blog Static Site

This folder is ready for static hosting.

## Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder in this directory, including `assets/`.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and select the repository root.
5. Save. GitHub provides the published URL after deployment.

## Included

- `index.html` — blog homepage and first article in one interactive file
- `assets/` — supplied RezLive service, product, accreditation, payment, and brand images
- Clickable first article; the two remaining articles remain grey trial entries

The CDN image links remain in the HTML for high-quality article imagery. The supplied RezLive visual assets are also included locally in `assets/` for future production integration.
